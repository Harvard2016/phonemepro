# PhonemePro web app

React + Vite. The whole app is static: the model runs in the browser with ONNX Runtime Web. See the [root README](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run lint
npm run build
```

`public/model/`, `public/lexicon/` and `public/audio/` are generated by the Python scripts in `../scripts/` and committed, so the app runs without them.
